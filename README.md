## Current work

My work at [Astrivant](https://github.com/astrivant) spans user-owned agent knowledge, adaptive services, and the infrastructure around them.

- **[Identity & Witful](https://github.com/astrivant/identity)**: Git-backed guidance, lessons, decisions, and evidence for people and their agents. Includes a Python library and CLI, record validation, and encrypted private snapshots.
- **Polyad**: adaptive service orchestration, focused on coordinating work and responding to changing demand within defined constraints.
- **[hypothesis-helm](https://github.com/astrivant/hypothesis-helm)**: property-based testing for Helm charts, with schema auditing and reproducible failing inputs.
- **[Composer](https://github.com/astrivant/composer)**: Helm-to-Docker Compose compilation, runtime profiles, and drift checks for local development.
- **[Minikube Cluster Autoscaler Addon](https://github.com/astrivant/minikube-cluster-autoscaler-addon)**: local worker autoscaling within configured limits. Requires a Minikube build containing its integration.
- **[resumeme](https://github.com/astrivant/resumeme)**: configurable résumés built from LinkedIn profiles, with versioned source and signed PDF releases.

## Plants & hardware

[Orchidarium](https://github.com/tigerlilyplants/orchidarium) is an environmental monitoring and control project for confined environments. Sensor collection, metrics publishing, a health/readiness API, and a Qt/QML interface run today; hardware actuation is still in development.

The [Tiger Lily Plants site and blog](https://github.com/tigerlilyplants/tigerlilyplants.github.io) cover the plant side of that work.
